ANDROID APP & TOUCH CONTROLS

🎮 Built-In Android Touch Controls Active!

Use the Left Virtual Thumb Joystick (bottom-left corner) to move your Necromancer smoothly in 360°, tap anywhere on the 3D battlefield to fire Soul Bolts, and tap the 6 Action Buttons at the bottom with your right thumb!

📲 Option 1: Instant Android Install (No PC Required)
  1. Open this game file in Chrome on your Android phone.
  2. Tap the Chrome menu (⋮) → Add to Home screen / Install App.
  3. Launch Undead Dominion full-screen from your Android app drawer with offline save support!
📦 Option 2: Build Native Android `.APK` (Android Studio Project)

Download the companion Android Studio Project ZIP provided in chat, open it in Android Studio, and click Build → Build APK(s) (or run ./gradlew assembleDebug) to generate a native installable Android .apk!
