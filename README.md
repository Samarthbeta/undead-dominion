# Undead Dominion: Rise of the Necromancer (Enhanced Edition)

An action-RPG dark fantasy Necromancer brawler built entirely in modern WebGL (Three.js) and HTML5 Canvas.

## Highlights & Features

- **Undead Horde 3rd-Person Perspective**: Over-the-shoulder follow camera positioned behind the Necromancer, framing the Necromancer in the lower third while opening up a wide forward view of the battlefield, enemy crusades, and strongholds ahead.
- **Adaptive War Council & NEAT-style Tactics Engine**: Enemy crusade commanders learn and evolve counter-tactics against your army composition (Phalanx cleave stances, anti-air volleys, targeted flank charges).
- **Summoning & Army Management**: Resurrect fallen enemies into dread chickens, venom scorpions, bone knights, wailing banshees, mummies, and titan dracoliches.
- **Widescreen & Mobile Responsive**: Native support for landscape 16:9 desktop/mobile widescreen as well as vertical mobile portrait mode with touch controls.
- **Gothic PBR Visuals**: Atmospheric dark-fantasy lighting with emerald soul fires, violet moonlight, runic seals, and dynamic shadow mapping.
- **Built-in God-Mode & Fast Iteration Cheats**: Access the War Council Grimoire [T] or Settings to test unit balance, grant currency, and toggle god-mode.

| **Unholy Charge** | `Q` / `2` | ⚔️ Charge Button |
| **Death Nova** | `E` / `3` | 💥 Nova Button |
| **Summon Swarm** | `C` / `4` | 🛡️ Summon Button |
| **Recall to Crypt** | `H` | Recall Button |
| **Waygate Advance** | `T` | Waygate Button |
| **Grimoire / Upgrades** | `Tab` | 📖 Grimoire Button |
| **War Council Tactics**| `T` / Grimoire Tab | 🧠 Tactics Tab |

| **Fullscreen** | `F11` | ⛶ HUD Button |

## Quick Start

Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Brave, Safari). No build tools, servers, or external npm packages required.
